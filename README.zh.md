# Light Stats

一款 macOS 菜单栏应用，实时监控 CPU、GPU、内存、磁盘和网络使用情况。点击任意项目可在弹窗中查看详情，支持内存清理。

> 英文版 README 请查看 [README.md](README.md)

---

## 功能简介

Light Stats 常驻菜单栏，实时显示系统指标，无需额外窗口。

**设计原则：**

- 信息常驻菜单栏，随时可见
- 固定宽度布局，避免数字变化导致界面跳动
- 专注监控，清理为辅
- 协议抽象 + 依赖注入，便于测试和扩展

---

## 功能详情

### 菜单栏状态栏

两行布局：

- 上行：数值（`62%`、`99 GB`），11pt 等宽字体
- 下行：标签（`CPU`、`DISK`），8pt，浅色
- 网络项：上行上传速度 ↑，下行下载速度 ↓，10pt 等宽字体

固定宽度防止抖动（CPU 26pt，Disk 46pt）。可在设置中开关各项显示（Logo、CPU、GPU、MEM、Disk、Net、Fan）。

### 弹窗面板

点击菜单栏项目打开弹窗，包含两个标签页：

**概览：** CPU、GPU、内存环形进度条，核心使用率列表（带颜色渐变），网络速度，磁盘和风扇信息。

**内存：** 内存压力概览，App 列表按内存占用降序排列，支持正常关闭和强制退出（二次确认）。

### 设置

- 菜单栏显示项目开关
- 刷新频率：低 (5s)、中 (2s)、高 (1s)
- 单位：温度 (℃/℉)、网速 (自动/KB/s/MB/s)
- 语言：简体中文、English、日本語、跟随系统

## 技术栈

- Swift 5.9+
- SwiftUI（弹窗/设置）+ AppKit（菜单栏/绘制）
- Combine + Swift Concurrency
- macOS 14+
- Mach API、IOKit、SMC、getifaddrs 获取系统指标

### 架构设计

每个监控维度有独立的读取器和管理类。通过 `ProcessService`、`SettingsManaging` 等协议解耦实现。依赖注入通过构造函数或属性注入，便于测试。全局常量集中在 `AppConfig` 管理。

## 文件结构

- `Models/`: 基础数据结构（CPUInfo, DiskInfo 等）
- `Services/`: 系统级数据采集（ProcessService, SMCInfo）
- `ViewModels/`: 业务逻辑与状态管理（SystemMonitor, AppMemoryManager, SettingsManager）
- `Views/`:
  - `StatusBar/`: 菜单栏绘图逻辑
  - `Popover/`: 弹窗面板组件与标签页视图
  - `Settings/`: 设置页面 UI
- `Resources/`: 国际化资源文件（`Localizable.strings`）
- `Utilities/`: 格式化工具与通用辅助方法
