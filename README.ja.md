# Light Stats

Light Stats は、CPU・GPU・メモリ・ディスク・ディスク I/O・ネットワーク・プロキシ経路・バッテリー・温度・ファン・プロセス・AI サブスクリプション使用量、そしてシステム全体の健康度を表示する、コンパクトな macOS メニューバー監視アプリです。

## 概要

Light Stats は主要なシステム指標をメニューバーに常時表示し、詳細が必要なときには浮動パネルを開けます。Activity Monitor を開きっぱなしにせず素早く状態を確認したいユーザーや、ネイティブな SwiftUI/AppKit のメニューバー監視実装を参考にしたい開発者に向けて設計されています。

アプリは通常のサンプリングに macOS ネイティブ API を使用し、ネットワークを伴う診断機能は既定でオフです。

## 機能

### メニューバー

- コンパクトな 2 行のステータス項目
- 固定幅の数値でレイアウトのちらつきを防止
- Logo・CPU・GPU・MEM・Disk・Net・Fan・Battery・Health を任意に表示
- ネットワークのアップロード／ダウンロード速度表示
- 健康度スコアの任意表示

### 概要パネル

- CPU・GPU・メモリ・ロードアベレージ
- 対応機種ではバッテリー状態・残量・充放電回数・状態・電力・温度
- ディスク使用量と集約ディスク I/O 速度
- ネットワーク速度・ローカルプロキシ状態・任意の公開出口ノード情報
- 温度・ファン・ディスク状態のステータスバー
- CPU プロセスのランキングと P/E コア使用率グラフ
- システム健康度スコアと各項目のサマリー
- AI 監視を有効にすると Claude Code と Codex のサブスクリプション使用量

### メモリクリーンアップ

- メモリ圧迫状況の概要
- スワップ警告
- メモリ使用量順に並べた App 一覧
- 通常終了と確認付きの強制終了
- 子プロセスの詳細を展開表示

### ネットワークとプロキシ

Light Stats は環境変数・システムプロキシ設定・アクティブなトンネルインターフェースからローカルプロキシ構成を検出します。この処理で外部リクエストは発生しません。

公開出口ノードの検出は任意です。有効にすると、選択した geo-IP プロバイダに公開 IP・位置・ASN・ISP を照会し、結果をキャッシュして繰り返しの要求を避けます。

### AI サブスクリプション使用量

有効にすると、Light Stats は Claude Code と Codex の CLI がローカルに保存した認証情報を読み取り、現在のサブスクリプション利用率（5 時間／7 日のウィンドウ）を概要パネルに表示します。AI 監視は既定でオフで、認証情報は各プロバイダ自身の使用量エンドポイント以外には送信されません。

### 健康度スコア

健康度スコアは CPU・メモリ・ロードアベレージ・ディスク使用量・温度・バッテリー・ディスク I/O を 0〜100 のスコアに集約します。機種が一部のセンサーを備えない場合、任意項目の重みは自動的に再配分されます。

---

## プライバシー

出口ノードの検出は既定でオフです。ローカルプロキシ検出は外部サービスに接続しません。

出口ノード検出を有効にすると、アプリは選択した geo-IP プロバイダにリクエストを送り、現在の公開 IP とネットワークの所有者を識別します。結果は 60 秒間キャッシュされ、失敗時は静かにフォールバックします。

---

## 設定

- メニューバー項目の表示切り替え
- 更新頻度：低 (5s)、中 (2s)、高 (1s)
- 温度単位：摂氏または華氏
- ネット速度単位：自動、KB/s、MB/s
- 出口ノード検出とプロバイダの選択
- AI 監視の切り替え（Claude Code と Codex の使用量）
- 言語：简体中文、English、日本語、한국어、システム言語

## 開発

### 動作要件

- macOS 14+（macOS 26 Liquid Glass の視覚スタイルに対応）
- Xcode 16 以降を推奨
- Swift 5.9+

### 技術スタック

- パネルと設定に SwiftUI
- メニューバー統合とカスタム描画に AppKit
- Combine と Swift Concurrency
- Mach API・IOKit・CFNetwork・Network・SMC・getifaddrs

### アーキテクチャ

アプリはモデル・サービス・ビューモデル・ビューの層に分かれています。`SystemMonitor` がサンプリングを統括して UI にスナップショットを発行し、各サービスが対応する指標を収集します。

キャッシュや非同期が必要な収集器（出口ノードやバッテリーのスマートデータ読み取りなど）は actor を使用します。軽量なローカルヘルパーは適切な場面で同期のまま保ちます。

### プロジェクト構成

- `Light Stats/Models/`: 指標のデータ構造
- `Light Stats/Services/`: システムデータ収集とスコアリング
- `Light Stats/ViewModels/`: アプリ状態とサンプリングの統括
- `Light Stats/Views/StatusBar/`: メニューバー描画
- `Light Stats/Views/Popover/`: 浮動パネル UI
- `Light Stats/Views/Settings/`: 設定 UI
- `Light Stats/Resources/`: ローカライズ文字列
