# Light Stats

Light Stats は、「いま Mac に負荷がかかっているか」を示すネイティブ macOS メニューバー型の状態計器です。0〜100 の健康度とリアルタイム信号を表示し、必要に応じて AI CLI 使用量、ネットワーク出口、Finder 操作、ウィンドウ配置、既定入力ソース、ディスプレイ輝度、スリープ防止を追加できます。ポップオーバーは 4 つの視覚テーマに対応し、クリーンインストール時はインクナイトが選択されます。設定ウィンドウはシステム白のツールパネルのままです。Apple Silicon 専用です。

## 概要

Light Stats は Mac のライブな負荷シグナルをメニューバーに常時表示し、必要なときに詳細な浮動パネルを開けます。Activity Monitor を開きっぱなしにせず状態を確認したいパワーユーザーや、AI エージェント、ネットワーク、Finder の作業コンテキストも近くに置きたい開発者向けです。

通常のサンプリングには macOS ネイティブ API を使用しています。モニタリングは読み取り専用のコアで、開発者向け・システム向けのツールは設定から有効にします。

## 機能

### メニューバー

- 固定幅の数値でレイアウトのちらつきを抑えるコンパクトな 2 行表示
- Logo・CPU・GPU・メモリ・ディスク・ネットワーク・ファン・バッテリー・健康度を任意に表示
- アップロード／ダウンロード速度表示
- ファン状態を回転アイコン風に表示
- 0〜100 の健康度スコアを任意表示

### 概要パネル

- CPU・GPU・メモリ圧迫・スワップ活動・ロードアベレージ
- P/E コア使用率グラフと CPU プロセスランキング
- 対応機種ではバッテリー状態・残量・充放電回数・健康度・消費電力・温度
- ディスク容量と集約ディスク I/O 速度
- ネットワーク速度・ローカルプロキシ状態・任意の公開出口ノード情報
- 内蔵／外付けディスプレイの任意のハードウェア輝度(DDC、既定オフ)
- 温度・ファン・熱状態・ディスク状態のステータスバー
- システム健康度スコア、各次元の概要、次元ごとの切り替え
- AI 監視を有効にすると 15 社のサブスクリプション使用量（クォータ枠とプリペイド残高）
- 主要指標の短期スパークライン
- 指標アイコンはテンプレート着色可能な SVG アウトライン(CPU・GPU・メモリ・ディスク・ネットワーク・プロキシ・温度・プロセス)

### 外観

- 製品面(ポップオーバー、About、Toast、更新、権限案内)向けに 4 テーマ:
  - **クラシック**:システムの計器表示(カード枠なし。macOS 26+ は Liquid Glass、macOS 15 は通常のシステム表面)
  - **ゴールデンアワー**:暖かな金色のグレインとネオン調の光
  - **アンバー**:暗いカクテルバーを思わせる背景に赤と緑のネオン
  - **インクナイト**(コールドスタート既定):墨黒のグレインと冷たいチャコール表面
- ゴールデンアワー / アンバー / インクナイトにはテーマごとの外観調整があり、フィルムグレインのオンオフと、光の動き 5 段階(静止・穏やか・自然・滑らか・活発)を設定可能
- 設定ウィンドウはシステム白のまま表示テーマに追従せず、落ち着いたツールパネルとして保つ

### メモリクリーンアップ

- メモリ圧迫状況とスワップ警告
- メモリ使用量順に並べた App 一覧
- 通常終了と確認付きの強制終了
- 子プロセスの詳細を展開表示
- レイアウトは instrument 読み出し:セクション・ヘアライン・高密度行

### Finder メニュー

- 既定でオフの FinderSync 拡張
- 選択したファイルのパスや名前をコピー。空白部分から現在のフォルダのパスもコピー可能
- テキスト、コード、Word、Excel、PowerPoint ファイルを作成。既定では TXT と Markdown を表示し、他の形式は設定で選択
- 既存のファイルをテンプレートとして取り込み、名前・形式・内容を保持。元のファイルを移動・削除しても利用可能
- よく使うフォルダへ移動・コピー。「その他の場所…」から保存先をその都度選択することも可能
- よく使うフォルダを直接開くほか、選択したターミナルや App で現在のフォルダやファイルを開く
- 選択項目の非表示・再表示。隠しファイルの表示は確認後に Finder 全体の設定を変更し、Finder を再起動
- 任意の cmux ウインドウ・ワークスペース操作と、メニュー項目ごとの表示設定
- ホームフォルダ、外付けボリューム、追加したよく使うフォルダに対応。クラウドフォルダでは他の Finder 拡張やシステムの状態による制限あり
- 設定で拡張の登録状態を確認し、Finder を再起動可能

### ウィンドウ管理

- 単一の**「ウィンドウ管理」スイッチ**（既定でオフ）で、メニューバーのウィンドウ操作アイコン・グローバルなスナップショートカット・タイトルバージェスチャーを一度にまとめて有効化します。個別のサブ切り替えはありません
- 配置は macOS 自身のウィンドウメニュー分割を優先し、`AXIdentifier` で照合します（ローカライズされたタイトルは使いません）。三分割・ディスプレイ移動・最小化だけがアプリ独自の幾何を使います
- デザイナー提供のアイコン付きウィンドウ操作メニュー
- 左半分・右半分・上半分・下半分にショートカットを割り当て、高頻度操作を優先
- `Control + Option + Return` で最大化、`Control + Option + C` で中央配置
- 角、三分割、ディスプレイ移動、最大化、中央配置、復元、最小化をメニューから実行
- タイトルバーのトラックパッドスワイプ：タイトルバー帯は信号ボタンから測り、アプリ自身が反応するコントロール上では開始しません。**Fn** を押すとポインタ下のウィンドウを吸着します（独自タイトルバーの App 向け）
- 設定には macOS 純正の端ドラッグ分割スイッチも出します（macOS 15+）。ウィンドウ管理を初めてオンにしたとき、端ドラッグを一度だけオンにします
- スイッチをオフにするとアイコンを直ちに削除し、ウィンドウ操作のイベント tap をすべて停止します。アクセシビリティ権限はオンにしたときにのみ要求されます

### 既定の入力ソース

- 任意：App を切り替えたあと、選んだ入力ソースへ戻す
- 既定オフ。アクセシビリティ権限は不要
- App が前面になった直後の短い窓でのみずれを直すので、その後の `Ctrl+Space` はそのまま。セキュア入力欄には触れません
- グローバルな既定が一つだけ。入力メソッド管理ではありません（App 別・サイト別ルールやインジケータはありません）

### スクロール方向制御

- 垂直／水平スクロール方向を個別に反転
- 既定では従来型のマウスホイールだけを対象とし、必要に応じてトラックパッド / Magic Mouse も反転対象に追加
- マウスホイールの加速を無効にし、イベントごとのスクロール量を 1〜10 行に固定可能
- 方向反転時のスクロール量を 0.25〜3.0 倍で調整するステップ倍率
- 関連機能が有効なときだけイベント tap を起動

### マウスを探す

- 好きなトリガーを録音（左右の修飾キー、Fn、F キー、通常キー、または組み合わせ）。2回押しで全画面を暗くしポインタをスポットライト表示、3回押しで常駐のプレゼンテーションポインタを切り替え
- スポットライトはポインタに追従し、クリックまたはキー入力でフェードアウト。4秒の安全タイムアウト付き。プレゼンテーションポインタはもう一度 3 回押しで閉じる
- イベントを遮断・改変しない listen-only のイベント tap。アクセシビリティ権限が必要で、デフォルトはオフ
- Pro：贈呈期間中に起動したユーザーは Pro を生涯保持。有料化後の新規ユーザーは設定 → 一般でアクティベーションコードを使います。MIT のまま、Ed25519 でオフライン検証、ネットワーク不要

### クリーンアップのショートカット

- 任意のグローバルショートカットで、メニューバーをクリックせずポインタ位置にクリーンアップを開く
- デフォルトはオフ。Carbon ホットキーで、アクセシビリティ権限は不要
- 初期値は ⌃⌥⌘U。キーは録音できる

### 清掃モード

- キーボード清掃のために 60 秒間キーボード入力をロック
- 全画面の半透明オーバーレイとカウントダウン
- マウスだけで終了できるボタン。キーボード入力は抑止
- CGEventTap を使用し、アクセシビリティ権限が必要

### スリープ防止とログイン時起動

- ポップオーバーのツールバーにあるクイック切り替えで、アクセシビリティ権限なしにディスプレイのスリープを防止
- クイック切り替えをオフにするか Light Stats を終了すると直ちに停止
- macOS のネイティブログイン項目サービスでログイン時起動を設定

### 更新

- 手動確認と任意の自動確認は Cloudflare R2 のチャネルマーカー（`latest-stable.json` / `latest-beta.json`）を読み、GitHub Releases にフォールバック。自動確認は既定でオフ
- 更新チャネル:**Stable**(正式版のみ)または **Beta**(`v1.9.0-beta.N` などの prerelease も含む)
- SemVer 2.0 でプレリリース識別子を正しく比較し、beta の増分と正式版への昇格を判別
- R2 ダウンロードは SHA-256 も検証し、その後 codesign 署名・公証・Team ID を検証
- アプリ終了後に独立スクリプトで app bundle を置き換え
- ダウンロードとインストール中は軽量な進捗ウィンドウを表示

### 診断とパフォーマンス記録

- ローカルの構造化障害ジャーナルは常時オン（オフ / エラーのみ / フルの切り替えはない）。連続指標は時間間引き、能力とプローブは初回観察と状態変化で書く
- 設定から診断 ZIP を書き出せる（システム環境、ハードウェア探査、直近 7 日のログ、上限 50 MB）。シリアル番号・資格情報・ユーザー名・ホームパスは伏せ、アップロードしない
- 別系統の 48 時間パフォーマンス記録（既定オフ）は、本アプリの CPU・メモリ・ウェイク・ディスクと付随するシステム負荷だけを取る。障害ジャーナルにも診断レポートにも混ざらない

### ネットワークとプロキシ

Light Stats は環境変数・システムプロキシ設定・アクティブなトンネルインターフェースからローカルプロキシ構成を検出します。この処理で外部リクエストは発生しません。

公開出口ノードの検出は任意です。有効にすると、選択した geo-IP プロバイダに公開 IP・位置・ASN・ISP を照会し、結果をキャッシュして繰り返しの要求を避けます。

### AI サブスクリプション使用量

有効にすると、Light Stats は各プロバイダの CLI がローカルに保存した認証情報、または設定で貼り付けた API token（Keychain 保存）を読み取り、そのプロバイダから現在のサブスクリプション利用率を取得します。AI 監視は既定でオフで、認証情報が別のプロバイダや Light Stats 開発者に送られることはありません。

Claude Code と Codex には、別々の使用量ウィンドウ保活スイッチがあります。どちらも既定でオフです。ローリングウィンドウのリセット後、一時的な空のディレクトリから各 CLI を通じて最小プロンプト `ok` を送信し、通常出力を破棄して新しいウィンドウを確認します。Gemini にはこの機能はありません。

### 健康度スコア

健康度スコアは CPU、メモリ圧迫とスワップ、ロードアベレージ、温度、GPU、電源状態を 0〜100 のスコアに集約します。ディスク容量のような変化の遅い数値ではなく、現在の応答性に影響する圧迫シグナルを重視します。ノート Mac ではバッテリー状態、デスクトップ Mac ではディスク I/O 圧迫を電源次元として扱います。欠落または無効化された次元の重みは自動的に再配分されます。

## プライバシー

ローカルシステム指標、ローカルプロキシ検出、プロセス一覧、スクロール動作、ウィンドウ操作は Mac 上に留まります。各ネットワーク機能が何を送るかは以下に記載しています。

- 出口ノード検出は、選択した geo-IP プロバイダに公開 IP、位置、ASN、ISP を照会し、結果を 60 秒間キャッシュします。
- AI 監視は、有効にしたプロバイダ自身の使用量エンドポイントだけに接続し、その CLI が保存済みの認証情報を使用します。
- 任意の Claude/Codex 保活は、上記の最小プロンプトを各プロバイダの CLI から送信します。
- 手動更新確認と任意の自動確認は Cloudflare R2 に接続し、GitHub Releases にフォールバックします。ダウンロード後は SHA-256（R2）、署名、公証、Team ID を検証します。
- 障害ジャーナルはディスク上に常時残り、診断レポートの書き出しはユーザー操作です。パフォーマンス記録は別の任意セッションです。どちらも Light Stats 開発者へは送られません。

詳細は[プライバシーポリシー](https://evilirving.github.io/light-stats/#privacy)を参照してください。

## 設定

- 視覚テーマ(クラシック / ゴールデンアワー / アンバー / インクナイト)と、ゴールデンアワー / アンバー / インクナイトごとのフィルムグレイン・光の動き
- メニューバー項目の表示切り替え
- 更新頻度：低 (5s)、中 (2s)、高 (1s)
- 温度単位：摂氏または華氏
- ログイン時起動、自動更新確認、Stable/Beta チャネル
- 診断レポートの書き出しと、任意の 48 時間パフォーマンス記録
- 出口ノード検出とプロバイダの選択
- 15 社の AI 監視と、Claude/Codex 個別の保活スイッチ
- 垂直／水平スクロール反転、トラックパッド / Magic Mouse の対象指定、マウスホイール加速の無効化、固定行数、ステップ倍率
- App 切替後に戻す既定入力ソース
- ウィンドウ管理（メニューバーアイコン・スナップショートカット・タイトルバージェスチャーをまとめる単一スイッチ）と、macOS 純正の端ドラッグ分割
- ディスプレイのハードウェア輝度（DDC）
- Finder メニュー、ターミナル選択、cmux 操作、お気に入りフォルダ、App、ファイルテンプレート
- 健康度スコアの次元切り替え
- 言語：简体中文、English、日本語、한국어、システム言語

設定のサイドバーには「一般」「モニタリング」「入力デバイス」「ウィンドウ管理」「AI 使用量」「右クリックメニュー」の 6 つの移動先があり、状態ドットは表示しません。ウィンドウはシステム白の固定キャンバスで、表示テーマはポップオーバーなど製品面のみに適用されます。スリープ防止は設定項目ではなく、ポップオーバーのツールバーから直接切り替えます。

## 開発

詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

### 動作要件

- macOS 14+（Apple Silicon）
- Xcode 16 以降を推奨
- Swift 5.9+
- ローカル lint には SwiftLint (`brew install swiftlint`)

### ビルド

```bash
# 本番パッケージを /Applications/Light Stats.app に上書きして起動
./script/local-run.sh

# Release DMG（インストールしない）
./script/build.sh
```

### 品質チェック

```bash
swiftlint lint --strict
./script/validate_localization.sh
```

GitHub Actions は SwiftLint、ローカライズ検証、Release ビルド、成果物アップロード、タグでの署名／公証、GitHub Release 作成を実行します。

### テスト

XCTest スイートは `LightStatsTests/` にあり、Xcode プロジェクトに組み込まれています（共有
`Light Stats` スキーム上の `LightStatsTests` ユニットテストターゲット）。CI と以下のコマンドの
両方で実行されます。カバレッジはリグレッションしやすい純粋ロジックに集中しています：
`HealthScoreService` のスコア曲線、設定の既定値、そして 3 つの AI 使用量 JSON
パーサー（フィクスチャは `LightStatsTests/Fixtures/`）。

```bash
xcodebuild test \
  -project "Light Stats.xcodeproj" \
  -scheme "Light Stats" \
  -destination 'platform=macOS'
```

### 技術スタック

- パネルと設定に SwiftUI
- メニューバー統合、ポップオーバー、オーバーレイ、カスタムビューに AppKit
- Combine と Swift Concurrency
- Mach API、IOKit、Accessibility、Core Graphics event tap、CFNetwork、Network、SMC、getifaddrs

### アーキテクチャ

アプリはモデル・サービス・ビューモデル・ビューの層に分かれています。`SystemMonitor` がサンプリングを統括して UI にスナップショットを発行し、各サービスが対応する指標を収集します。

キャッシュや非同期が必要な収集器（出口ノード照会や AI 使用量プロバイダなど）は actor を使用します。UI に紐づく状態は main actor に留めます。高速な syscall ヘルパーは適切な場面で同期のまま保ちます。

### プロジェクト構成

- `Light Stats/Models/`: 指標データ構造、健康度、リリース情報、`AppTheme`
- `Light Stats/Services/`: システム収集、スコアリング、更新、スクロール反転、ウィンドウスナップ、ホットキー、タイトルバージェスチャー、キーボードロック、AI 使用量、診断ログ
- `Light Stats/ViewModels/`: アプリ状態、サンプリング、設定、清掃モード、更新統括
- `Light Stats/Views/StatusBar/`: メニューバー描画
- `Light Stats/Views/Popover/`: 浮動パネル UI と再利用コンポーネント
- `Light Stats/Views/Theme/`: テーマトークン、メッシュ背景、グレイン、ピッカー、外観プリセット
