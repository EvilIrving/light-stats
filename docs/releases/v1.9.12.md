## Light Stats 1.9.12

这一版把 Antigravity 的额度按「存在多少条就显示多少条」列出来。此前每个模型池只显示更吃紧的那一个窗口，于是同时有 5 小时与每周额度时，只看得见其中一条。现在每个窗口单独一行，行首标出它属于哪个池：`Gemini` 与 `Other`（Claude、GPT 等第三方模型）。窗口类型仍是 `5h` / `7d`。

This release lists every Antigravity allowance that exists instead of one row per model pool. Each pool meters a 5-hour and a weekly window separately, so collapsing them to the tighter one hid a quota that was still available. Every window now gets its own row, led by the pool it belongs to: `Gemini` and `Other` (Claude, GPT and the other third-party models). The window kind stays `5h` / `7d`.

### 修复

- Antigravity 的每个窗口各占一行，5 小时与每周额度不再互相遮挡 / Each Antigravity window gets its own row, so the 5-hour and weekly allowances no longer hide each other
- 模型池名称改为 `Gemini` 与 `Other`，不再把两条独立额度写成一组 / The pools are labelled `Gemini` and `Other` instead of presenting two separate allowances as one

### 已知情况

- Gemini 的**每周**额度目前没有出现在接口响应里（组摘要不再返回 Gemini 组，按模型接口只给短窗口）。接口一旦返回该窗口，它会自动出现在这一组里 / Gemini's **weekly** allowance is not currently in the API response — the group summary stopped returning the Gemini group and the per-model body carries only the short window. It appears automatically once the API reports it.
