## Light Stats 1.9.5

修复应用内更新的可靠性。此前某些版本会在更新窗口切换状态时崩溃，安装没完成、用户也没有任何反馈；替换过程还可能先删掉旧包。1.9.5 重做了安装交接：旧版本始终保留、失败自动回滚、重启后核对实际版本，并在失败时给出明确提示和手动下载入口。

A reliability release for in-app updates. Some earlier versions crashed while the update window changed state, so the install never finished and the user got no feedback; the replace step could also delete the old bundle first. 1.9.5 rebuilds the handoff: the old version is always kept, failures roll back, the actual version is verified after a restart, and failures show a clear message with a manual download link.

### 修复

- 更新窗口在 macOS 26 上切换状态时可能崩溃导致安装未完成：窗口现在由 AppKit 持有固定尺寸，不再随内容自动缩放
- The update window could crash on macOS 26 while switching states, leaving the install unfinished: the window now keeps an AppKit-owned fixed size instead of resizing with its content
- 替换不再先删旧包：旧版本先保留为备份，移动或启动失败会自动回滚；等待旧进程退出超时会中止并保留旧包
- Replacement no longer deletes the old bundle first: the previous version is kept as a backup, move and launch failures roll back, and an exit timeout aborts while keeping the old app
- 重复安装与换包期间的误清理被阻止：跨进程锁保证同一时间只有一个安装器，且安装器结束前不会清理暂存文件
- Duplicate installs and premature cleanup are blocked: a cross-process lock keeps one installer at a time and stops cleanup while it is still running
- 重启后核对实际运行版本：成功显示已安装版本；失败显示目标版本、当前版本和手动下载页面，并把失败阶段写入诊断日志
- The actual running version is verified after a restart: success shows the installed version, failure shows the target and current versions plus the manual download page, and the failing stage is written to the diagnostic journal
- 本次无法修复已运行旧版的更新动作：若你的旧版本在更新过程中崩溃过，需从下载页面手动安装一次；之后的应用内更新即自行恢复
- This release cannot repair an old version's running update action: if an older version crashed mid-update, install once manually from the download page; in-app updates then recover on their own
