## Light Stats 1.9.9

这一版修复 Dock 图标点击折叠在 Dock 处于自动隐藏时的失效问题。此前的判定区域取自「可见区域与整屏区域的差值」，而自动隐藏的 Dock 不占任何空间，差值为零——于是每次点击都在询问 Dock 之前就被判为不在 Dock 上，功能看起来完全没反应。现在判定区域改为「保留区域与 192 pt 取较大值」，同时覆盖自动隐藏的 Dock 与放大后绘制在底板之外的大图标，真正的命中仍由 Dock 自己回答。

This release fixes Dock-click window collapse when the Dock is set to hide automatically. The detection band used to come from the visible-frame difference, and an auto-hidden Dock reserves no space at all, so the band was zero — every click was rejected before the Dock was ever asked, which made the feature look like it did nothing. The band is now the larger of the reserved space and 192 pt, covering both an auto-hidden Dock and a magnified tile drawn above the Dock's own plate, while the Dock itself still answers the actual hit test.

### 修复

- Dock 自动隐藏时点击图标折叠/恢复窗口不再失效 / Dock-click collapse and restore no longer fail when the Dock hides automatically
- 放大后的 Dock 图标绘制在底板之外时也能正确命中 / A magnified Dock tile drawn beyond the Dock's plate is now hit correctly
