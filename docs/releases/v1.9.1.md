## Light Stats 1.9.1

相对 **v1.9.0** 的正式版（包含全部 1.9.1 beta 周期）。

### ✨ 新功能 / Features

**主题 / Themes**

- 四种外观：经典、黄金时刻、琥珀、墨夜；干净安装默认墨夜。已删除 Bento 与灰纱
- Four looks: Classic, Golden Hour, Amber, and Ink Night. Ink Night is the clean-install default. Bento and Ash Veil are removed
- 黄金时刻 / 墨夜使用动态光场；所有主题都是无内容卡片的 instrument 布局
- Golden Hour and Ink Night use dynamic light fields; every theme uses the card-free instrument layout
- 设置窗保持系统浅色；主题只作用在产品界面
- Settings stays system light; themes apply only to product surfaces

**输入与窗口 / Input and Windows**

- 滚动控制可选纳入触控板与 Magic Mouse；可关闭滚轮加速度并固定每格 1–10 行
- Scroll controls can include trackpad and Magic Mouse; wheel acceleration can be off, with a fixed 1–10 lines per notch
- 新增 `Control + Option + Return` 最大化与 `Control + Option + C` 居中
- New `Control + Option + Return` maximize and `Control + Option + C` center shortcuts

**唤醒、显示与记录 / Wake, Display, and Recording**

- 弹窗工具栏可开关保持唤醒；接电合盖时可选用虚拟显示器
- Keep-awake toggle in the popover toolbar; optional virtual display for clamshell on AC
- 可选显示器亮度硬件控制（DDC，默认关闭）
- Optional hardware display brightness (DDC, off by default)
- 可记录约 48 小时本机性能；趋势折线会保留最近三小时
- Optional ~48-hour local performance recording; trend sparklines keep the last three hours

**设置 / Settings**

- 设置侧栏改为通用、监控、输入设备、窗口管理、AI 用量、右键菜单六个直达入口
- Settings sidebar has six direct destinations: General, Monitoring, Input Devices, Window Management, AI Usage, and Right-Click Menu

### 🔧 优化 / Improvements

- 状态栏风扇改为 Core Animation，减少主线程绘制
- Status-bar fan uses Core Animation to cut main-thread drawing
- 主题预览、动态着色与行样式调整；取消「黑白界面」开关
- Theme previews, dynamic colors, and row styles reworked; monochrome-UI switch removed

### 🐛 修复 / Fixes

- 滚动反转同时改写 CGEvent 与 IOHID，自然滚动下方向更一致；睡眠唤醒后会恢复事件 tap
- Scroll reversal updates CGEvent and IOHID together for Natural Scrolling; the tap recovers after wake
- 修复更新校验管道卡死、退出阶段卡死，以及公证票据未内嵌导致的安装失败
- Fixed update verification hangs, a quit-time deadlock, and missing notarization tickets
- 修复浮层空白点击穿透，以及取消标题栏手势仍提交窗口吸附
- Fixed popover click-through and titlebar-gesture cancels that still snapped the window
