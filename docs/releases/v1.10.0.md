## Light Stats 1.10.0

这一版正式上线两件事：⌘Tab 窗口切换器和窗口缩略图。切换器保留系统那套「先选 App、再选窗口」的两级形态，也可以换成网格，把一次会话里的所有窗口平铺成一张网任你挑。跨 Space 的窗口现在能被读到、能切过去、也能拍到缩略图。权限入口也不再是「打开系统设置」就把你放下：现在把 Light Stats 图标直接拖进列表，卡片会贴着你正在操作的那个设置窗口，授权一到就自己收尾。Dock 悬停预览仍未完成，继续隐藏。

This release ships two finished surfaces: the ⌘Tab window switcher and window thumbnails. The switcher keeps the system's two-level shape — pick an app, then one of its windows — and can switch to a grid that lays every window of the session out in one net. Windows on another Space can now be listed, brought forward, and captured. Permission prompts no longer drop you into System Settings and leave: you drag the Light Stats icon into the list, the card follows the Settings window you are actually working in, and it finishes itself once the grant arrives. The Dock hover preview is still unfinished and stays hidden.

### 新增

- ⌘Tab 窗口切换器上线，需开启窗口管理：Tab 换 App、方向键换窗口，松手切到选中的那个窗口 / The ⌘Tab window switcher ships with window management on: Tab moves between apps, the arrows between their windows, and releasing Command switches to the selection
- 切换器可换成网格布局：一次会话的所有窗口平铺成一张网，Tab、方向键和指针都移动同一个选中项 / The switcher can switch to a grid: every window of the session is laid out in one net, and Tab, the arrows, and the pointer all move the same selection
- 切换器布局在设置里选，没改过的安装仍是两级形态 / The layout is chosen in Settings, and an install that never touched it keeps the two-level shape
- 窗口缩略图上线，预览卡片显示真实画面；需要屏幕录制权限，未授权时仍是标题卡 / Window thumbnails ship, so preview cards show the real picture; they need Screen Recording, and a card without it is still a titled stand-in
- 跨 Space 的窗口可读、可聚焦、可拍缩略图：枚举、切前台与截图三条路都走同一套能力，符号缺失时退回公开 API 的行为 / Windows on another Space are listed, brought forward, and captured; enumeration, activation, and capture share one capability, which falls back to the public-API behaviour when the symbols are missing
- 权限入口改为拖拽授权引导：把 App 图标拖进系统设置的列表即可，卡片贴着设置窗口定位，授权后自动结束，需要重启时会直接说明 / Permission prompts are now a drag-to-grant guide: drop the app icon into the Settings list, the card docks beside the Settings window, it finishes on the grant, and it says so when a restart is required

### 改进

- 内置受限 App 列表常开：媒体播放器、游戏、远程桌面与全屏窗口不再可能被移动，设置页只添加你自己的排除项，也不再收录内置列表已拦下的条目 / The built-in restricted list always applies, so media players, games, remote desktops, and full-screen windows can no longer be moved; the settings page only adds your own exclusions and no longer accepts an entry the built-in list already covers

### 已知情况

- Dock 悬停预览仍未完成，本次不提供；它的偏好默认是开的，所以既没有开关行，也不会被存量偏好启动 / The Dock hover preview is still unfinished and is not offered; its preference defaults to on, so it has no switch row and no stored preference starts it
