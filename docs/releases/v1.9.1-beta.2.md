## Light Stats v1.9.1-beta.2

相对 **v1.9.0** 的补丁预发布（Prerelease）。开启「尝鲜（Beta）」更新通道后可收到；正式版用户不会被推送。

### ✨ 主题 / Themes

- 恢复晒金 / 墨夜动态 mesh 背景，并隔离面板滚轮，避免滚动穿透到后方窗口
- Restored dynamic mesh themes for Sun Gold / Ink Night, with panel scroll isolation so wheel events no longer pass through
- 重塑墨夜月光与水墨云层；自然光影动态更顺滑
- Redesigned Ink Night moonlight and ink clouds; smoother natural light motion
- 设置页主题预览放大，辨识度更高
- Larger theme previews in Settings for clearer comparison
- 工具窗（设置等）回归系统外观；主题只作用在产品展示界面
- Tool windows (Settings and similar) use system appearance again; themes apply only to product surfaces
- 冷启动默认主题改为墨夜
- Cold-start default theme is now Ink Night

### 🐛 修复 / Fixes

- 修复浮层空白区域点击穿透到下方窗口的问题
- Fixed popover blank-area clicks passing through to windows behind
- 取消标题栏手势时不再错误提交窗口吸附操作
- Cancelling a titlebar gesture no longer commits a window snap

### 🔧 优化 / Improvements

- 合并主题网格背景绘制，降低渲染开销
- Merged theme mesh draw groups to cut rendering cost
