## Light Stats 1.9.3

相对 v1.9.2 的正式版。

### 新功能

- AI 用量扩到 15 家：Claude Code、Codex、Gemini、Grok、Warp、Trae、OpenCode Go、Cursor、Kimi、Qoder、DeepSeek、Z.ai、MiniMax、OpenRouter、MiMo；一家一开关，默认全关
- AI usage covers 15 providers: Claude Code, Codex, Gemini, Grok, Warp, Trae, OpenCode Go, Cursor, Kimi, Qoder, DeepSeek, Z.ai, MiniMax, OpenRouter, MiMo; one switch each, all off by default
- 概览用量行折叠：多窗口只显示最紧的一条，点击展开全部；余额型沉底、只显示金额不画进度条
- Overview quota rows collapse to the tightest window, tap to expand; balance-only providers sink to the bottom with no bars
- 右键菜单：新建 Word / Excel / PowerPoint 与自定义文件模板；移动/复制到常用目录；隐藏/显示选中项
- Finder menu: Word / Excel / PowerPoint blanks and custom templates, move/copy to favorites, hide/show items
- 默认输入法：切换 App 后回到选定的系统输入源，默认关闭
- Default input source: return to your chosen input source after app switches, off by default
- 清理快捷键：在指针处打开清理页的可选全局热键，无需辅助功能权限
- Cleanup shortcut: optional global hotkey that opens Cleanup at the pointer, no Accessibility permission needed
- 诊断报告：故障日志始终开启，设置中可导出 ZIP；48 小时性能记录与故障日志永久分离
- Diagnostic reports: always-on fault journal with user-exportable ZIP; 48-hour performance recordings stay separate

### 调整

- 窗口管理改为原生优先：先按 macOS 窗口菜单分屏，失败再走自有几何
- Window management prefers macOS' own tiling, then falls back to its own placement
- Cursor 主窗口口径改为 auto（Cursor Models）百分比
- Cursor's primary window follows the auto (Cursor Models) percentage
- 仅支持 Apple Silicon，不再产出 x86_64 切片
- Apple Silicon only; x86_64 slices are gone

### 修复

- 应用退出恢复为即时完成；Grok 周额度重置边沿不再显示为「—」
- Instant quit is back; Grok no longer shows "—" at the weekly reset edge
