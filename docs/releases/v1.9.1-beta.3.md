## Light Stats v1.9.1-beta.3

相对 **v1.9.1-beta.2** 的补丁预发布（Prerelease）。开启「尝鲜（Beta）」更新通道后可收到；正式版用户不会被推送。

### ✨ 主题 / Themes

- 主题阵容收敛为四个：经典、黄金时刻、琥珀、墨夜（干净安装仍默认墨夜）；删除 Bento 与灰纱
- Streamlined to four themes: Classic, Golden Hour, Amber, and Ink Night (still the clean-install default); Bento and Ash Veil removed
- 夜色酒吧改为暖琥珀灯光 + 青蓝霓虹点缀，更名「琥珀」
- Night Bar re-lit as warm amber lamplight with a teal neon accent, renamed "Amber"
- 霓虹主题改用暖金黄铜仪表墨色，更名「黄金时刻」；移除两主题的竖直光束
- Neon re-inked in warm brass over the amber-and-coral light field, renamed "Golden Hour"; vertical beam layers removed
- 默认主题更名「经典」；所有主题统一无内容卡片的 instrument 布局
- Default renamed "Classic"; every theme uses the card-free instrument layout
- 取消「黑白界面」开关，指标动态着色恒定
- Removed the monochrome-UI switch; dynamic status coloring is always on

### ✨ 新功能 / Added

- 滚动控制可选纳入触控板与 Magic Mouse
- Scroll controls can now include trackpad and Magic Mouse
- 可关闭鼠标滚轮加速度，并固定每次滚动 1 到 10 行
- Wheel acceleration can be disabled, with a fixed 1–10 lines per notch
- 新增 `Control + Option + Return` 最大化与 `Control + Option + C` 居中快捷键
- New `Control + Option + Return` maximize and `Control + Option + C` center shortcuts
- 弹窗工具栏新增保持唤醒快捷开关
- Keep-awake toggle added to the popover toolbar

### 🔧 改进 / Changed

- 设置侧栏改为通用、监控、输入设备、窗口管理、AI 用量、右键菜单六个直达入口
- Settings sidebar split into six direct destinations: General, Monitoring, Input Devices, Window Management, AI Usage, and Right-Click Menu
- 主题预览、动态配色、趋势线与标签样式重新调整
- Theme previews, dynamic colors, trend lines, and row styles reworked
- 右键菜单文案精简为「右键菜单」
- Finder menu label shortened to "Right-Click Menu"

### 🐛 修复 / Fixes

- 滚动反转同时更新 CGEvent 与底层 IOHID 值，改善自然滚动开启时不同 App 的方向一致性
- Scroll reversal now updates both CGEvent and underlying IOHID values, fixing direction consistency across apps with Natural Scrolling on
- 水平滚动使用独立倍率，低倍率整数步进不会再舍入为零
- Horizontal scroll uses its own multiplier; low-multiplier integer steps no longer round to zero
- 睡眠唤醒、事件 tap 超时禁用及快速切换设置后会恢复或重建滚动 tap
- Scroll tap is recovered or rebuilt after wake, tap-disable timeouts, and rapid setting changes
