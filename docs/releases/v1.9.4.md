## Light Stats 1.9.4

相对 v1.9.3 的修复版。1.9.3 的右键菜单和更新安装都存在可用性问题，建议所有 1.9.3 用户升级。

### 修复

- 右键菜单点击无反应：菜单项改回按 tag 派发。FinderSync 把菜单编组交给 Finder 后，`representedObject` 到点击时已是 nil，导致所有动作静默返回——菜单弹得出来，点了什么都不发生
- Finder menu actions did nothing: items dispatch by tag again. FinderSync marshals the menu to Finder, so `representedObject` was nil by click time and every action returned silently — the menu appeared, but clicking it did nothing
- 粘贴 API token 保存后没有任何反馈：按钮现在会短暂显示「已保存」并弹一条提示，保存失败同样有提示，不再静默
- Saving an API token gave no feedback at all: the button now briefly shows a saved label and raises a toast, and failures are surfaced instead of being swallowed
- 更新安装可能失败：切到「安装中」那一步触发 AppKit 异常终止进程，而它发生在替换脚本启动之前，于是包没被换掉。现在替换脚本先脱离进程跑起来，之后即使崩溃也不再丢更新
- An update could fail to install: the installing-phase redraw tripped an AppKit exception that aborted the process before the replace script started, so the bundle was never swapped. The script now runs first, which makes such a crash harmless
- 本地构建会向系统留下未签名、未沙盒的同名 Finder 扩展，被 pkd 判为 mis-configured plugin，连带影响已安装的那一份
- Local builds left an unsigned, non-sandboxed copy of the Finder extension behind, which pkd rejected as a mis-configured plugin and which tainted the installed copy
