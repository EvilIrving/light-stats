## Light Stats 1.9.0

相对 v1.8.0 的正式版。

### 新功能

- 监控面板、关于、更新、权限提示跟随主题。黄金时刻 / 墨夜可调颗粒和光影
- Popover, About, Update, and permission prompts follow the theme. Grain and light motion on Sun Gold and Ink Night
- Finder 右键：终端、cmux、按类型命名的新建文件
- Finder menu: terminal, cmux, typed new-file names
- 更新通道可选正式版或 Beta。诊断日志只存在本机。自动检查更新默认关闭
- Update channel: Stable or Beta. Local diagnostic logs. Automatic update checks off on a clean install

### 修复

- Finder 选文件面板不再干扰滚动和窗口手势。清洁模式同时锁媒体键
- Finder pickers no longer fight scroll and window gestures. Cleaning mode also blocks media keys
- 笔记本识别、接电未充电、磁盘小数、pnpm 安装的 Codex 路径
- Laptop detection, AC-plugged-not-charging, disk decimals, and pnpm-installed Codex paths
