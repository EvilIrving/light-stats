## Light Stats 1.9.0

相对 **v1.8.0** 的正式版更新（包含全部 1.9.0 beta 周期内容）。

### ✨ 新功能 / Features

**主题与外观 / Themes**

- 四种外观主题：默认、Bento、晒金、墨夜
- Four visual themes: Default, Bento, Sun Gold, Ink Night
- 晒金与墨夜支持颗粒纹理、光影动态五档调节
- Sun Gold / Ink Night: grain toggle and five light-motion levels
- 监控面板、关于、更新与权限引导统一跟随所选主题
- Popover, About, Update, and permission prompts follow the active theme
- 指标图标升级为更清晰的 SVG 图标
- Metric icons upgraded to crisp SVG artwork

**Finder 扩展 / Finder Extension**

- 右键菜单支持选择终端、cmux 新窗口与新工作区
- Finder menu: pick a terminal, open cmux window / workspace
- 设置中可查看 Finder 扩展是否已注册并启用
- Settings shows real FinderSync registration / enablement status
- 新建文件按类型自动命名（如 index、main、notes）
- New-file templates use typed names (index / main / notes…)

**更新与诊断 / Updates & Diagnostics**

- 更新通道可选「正式版」或「尝鲜（Beta）」
- Update channel: Stable only, or include Beta prereleases
- 应用日志可选：关 / 仅错误 / 完整（本地保存，约 5 天）
- App log level: Off / Errors only / Full (local, ~5 days)
- 自动检查更新改为默认关闭，干净安装不会主动外联
- Auto-update check is off by default (zero outbound on clean install)

**设置与其它 / Settings & More**

- 设置页重组为「通用 / 监控 / 更多」三栏
- Settings reorganized into General / Monitor / More
- AI 用量失败时可一键重试；用量窗口保活更稳妥
- AI usage failures are retryable; usage-window keep-alive is more reliable
- 清洁模式仅在笔记本等便携式 Mac 上显示
- Cleaning mode appears only on portable Macs

### 🔧 优化 / Improvements

- 设置窗口固定系统浅色底，主题只作用于产品展示界面
- Settings stays system light; themes apply to product surfaces only
- 不同主题下概览与清理页布局更贴合各自风格
- Overview / Cleanup layouts adapt per theme
- 辅助功能权限引导改为应用内主题化面板（不再用系统弹窗）
- Accessibility prompts use an in-app themed panel instead of system alerts
- Finder 设置列表更紧凑，已启用扩展时不再提示去系统设置开启
- Finder settings lists are denser; hide “enable in System Settings” when already on
- 诊断日志降低冗余采样与敏感信息暴露
- Diagnostics cut noisy sampling and reduce sensitive data exposure

### 🐛 修复 / Fixes

- 修复 Finder 选文件/应用面板导致滚动与手势异常
- Fixed Finder file/app pickers fighting scroll and gesture services
- 清洁模式下同时封锁媒体键与功能键
- Cleaning mode also blocks media and function keys
- 修正笔记本识别、接电未充电状态与磁盘用量小数显示
- Fixed laptop detection, AC-not-charging state, and disk decimal display
- 兼容通过 pnpm 安装的新版 Codex 路径
- Compatible with newer pnpm-installed Codex paths
- 修复部分设置面板可能卡住的问题
- Fixed settings panels that could hang or deadlock
