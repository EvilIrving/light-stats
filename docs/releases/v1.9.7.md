## Light Stats 1.9.7

这一版新增对 Antigravity CLI 的 AI 用量监控，同时整体重写了中、英、日、韩四种语言的界面文案。只要本机登录过 Antigravity，面板就会自动读取已有授权，并在 5 小时与每周两行中分别显示更吃紧的一组模型配额。由于两者使用同一套后端与配额、读数完全重合，原有的 Gemini CLI 项已在此版移除。全局界面的提示文案去掉了冗余的技术细节与抱怨式措辞，统一了核心术语，更专注说明功能本身与操作。

This release adds AI usage tracking for the Antigravity CLI and delivers a complete copy overhaul across English, Simplified Chinese, Japanese, and Korean. If you already use the Antigravity CLI on your Mac, Light Stats picks up your existing login automatically, highlighting whichever model group is tighter across both the 5-hour and weekly windows. Gemini CLI has been removed because it shares the same underlying quota pool, which previously resulted in duplicate rows. Across the rest of the app, labels and tooltips now plainly describe what features do, dropping internal technical details and standardizing key terms.

### 新增

- 支持 Antigravity CLI（`agy`）AI 用量：直接读取命令行已保存在钥匙串中的授权，无需手动配置 Token
- Antigravity CLI (`agy`) usage tracking: reads authorization directly from the Keychain, with no manual token setup required
- 同一订阅内的多个模型组分别计量配额，面板的「5 小时」与「每周」两行各自显示更紧的那一组
- Independent model group tracking: the 5-hour and weekly rows each display whichever group is currently tighter

### 改进

- 移除 Gemini CLI 用量提供者：与 Antigravity 共用同一套后端配额，避免面板中出现重复读数
- Removed Gemini CLI usage tracking: both tools share the same backend quota pool, which caused duplicate readings on the panel
- 全面梳理中、英、日、韩四语的界面文案：提示信息改为直述功能与操作，移除技术实现说明与抱怨式措辞（如更新提示去掉面向审核的「已公证」字样，显示器亮度客观说明 DDC 兼容前提）
- Overhauled interface copy across English, Simplified Chinese, Japanese, and Korean: tooltips now directly describe features and actions instead of internal implementation details or hardware caveats (e.g., update prompts drop notarization jargon, and display brightness plainly explains DDC compatibility)
- 统一规范核心术语与界面标签：「找到我的鼠标」更名为「快速定位光标」（Locate Pointer / ポインタをハイライト / 포인터 위치 찾기），中文「状态栏隔离栏」更正为「状态栏分隔线」，AI 用量折叠项由「最紧额度」改为「仅显示主额度」，关于与退出菜单项补齐应用名
- Standardized key terminology across all four languages: renamed Find My Mouse to Locate Pointer (ポインタをハイライト / 포인터 위치 찾기), corrected the Chinese status bar divider label, updated the AI usage collapse toggle to "Show primary quota only", and restored the app name to About and Quit menu items
