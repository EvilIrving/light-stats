# 主题阵容规划（4 主题）

> 讨论结论的落地版本。目标：最终 4 个主题，彼此区分度足够，覆盖科技数码圈（95% 男性）的子人群，并兼顾少量女性用户。
>
> 状态：**讨论稿**，待执行。

## 一、现状

`AppTheme` 枚举现有 5 个 case，其中 `dataPaper` 被 `isVisible` 隐藏，实际可见 4 个：

| 枚举 | 中文名 | UI 定位 | 背景场景 (`BackgroundSceneID`) |
|---|---|---|---|
| `glass` | 默认 | 系统毛玻璃、克制 | `.systemGlass` |
| `film` | 霓虹 | 霓虹控制台 + 暖光场 | `.sunGold` |
| `bar` | 夜色酒吧 | 红绿霓虹 + 鸡尾酒吧 | `.bar` |
| `noir` | 墨夜 | 墨水 + 冷光场 | `.inkNight` |
| `dataPaper` | 数据纸 | （隐藏） | `.technicalPaper` |

> 注：`ashVeil`（灰纱）与 `bento`（Bento 网格）已彻底删除（枚举、场景、tokens、布局分叉、组件、资源、文案）。

## 二、诊断

核心问题不是数量，而是**区分度不够**：现有 4 个里有 3 个是「暗色 + 霓虹/光场」（霓虹、夜色酒吧、墨夜），视觉高度重叠。

另外 `film`（霓虹）挂着暖色 `sunGold` 背景，与「霓虹控制台」的名字自相矛盾。

## 三、最终 4 主题方案（按人格划分）

| # | 主题 | 覆盖人群 | 关键特征 | 明暗 |
|---|---|---|---|---|
| 1 | 默认（保留） | Apple 极简党 / 无所谓党 | 系统原生、透明、中性锚点 | 亮 |
| 2 | **墨夜（保留，旗舰）** | 程序员/极客/夜猫子 | 墨水黑 + 冷光、低饱和、沉浸 | 暗 |
| 3 | **赛博朋克（新增，替换夜色酒吧）** | RGB 装机党/电竞/硬核数码 | 高饱和青紫霓虹 + 网格 + 故障感 | 暗 |
| 4 | **暖阳（由「霓虹」重构）** | 女性 + 反暗黑党 + 治愈系 | 暖金/奶油、明亮、柔和 | 亮 |

改动：
- **夜色酒吧（灯红酒绿）→ 赛博朋克**：红绿霓虹的「鸡尾酒吧」气质最不讨科技男、也最劝退女性，换成赛博朋克填上「RGB 硬核」缺口。
- **霓虹（film）→ 暖阳**：复用现有 `sunGold` 场景，仅换 UI tokens + 文案，成本最低，同时解决「女性覆盖」和「明亮主题缺失」两个问题。

## 四、区分度坐标轴

让 4 个主题在三个轴上拉开距离，而非「换个颜色」：

1. **明度**：亮（默认、暖阳）→ 暗（墨夜、赛博朋克）
2. **色温**：中性（默认）→ 冷蓝黑（墨夜）→ 高饱和青紫（赛博朋克）→ 暖金（暖阳）
3. **质感**：毛玻璃 / 墨水 / 霓虹辉光 / 暖光

## 五、女性覆盖

关键不是「做粉红色」，而是提供「不刺眼的亮/柔」选项。能拉女性的是**暖阳**（明亮暖色 + 治愈）。保证 4 个里有 1–2 个柔和选项即可，不做专门的女性主题（刻意且制造隔离感）。

## 六、落地改动清单

架构：一个主题 = `UITokens` + `BackgroundSceneID` + `ThemeLayout`，组合表在 `ThemeDefinition.swift`，不能只改名。

| 改动 | 文件 | 成本 |
|---|---|---|
| 新增 `cyberpunk` case（或改造 `bar`） | `Light Stats/Models/AppTheme.swift` | 低 |
| 新增 Cyberpunk 场景（复用 `LightFieldLayer`，青/紫调色板） | `Light Stats/Views/Theme/Background/Scenes/` | 中 |
| 新增 cyberpunk UI tokens | `Light Stats/Views/Theme/UITokens.swift` | 中 |
| `film` → 暖阳：换 UI tokens，保留 `sunGold` 场景 | `UITokens.swift` + `ThemeDefinition.swift` | 低 |
| 文案（默认/墨夜/赛博朋克/暖阳） | 4 个 `Localizable.strings` | 低 |
| 主题选择器展示顺序 | `ThemePickerView.swift` | 低 |

中文名建议：赛博朋克、暖阳（备选「晨光」「奶油」）、墨夜、默认。
