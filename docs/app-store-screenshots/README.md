## Note for App Store edition

If the overview shots show **Pro** / keep-awake / cleaning-mode toolbar icons from a Direct build, either:

1. Re-capture from the **Light Stats AppStore** build (preferred), or
2. Keep as-is and rely on review notes that the store build omits those tools (riskier).

App icon: use `Light Stats/Assets.xcassets/AppIcon.appiconset/1024.png` (already 1024×1024).
